# RunStop 🚽

A mobile-first running map for Wellesley and surrounding towns (Natick, Needham, Newton).

**Live app:** https://andrewmyerson-atm.github.io/runstop

## Features
- 🗺 Map of coffee shops, gyms, and construction portapotties — bathroom stops for runners
- 🚽 Drop and share pins with your running group (Waze-style — stays until 2 people mark it gone)
- 🌲 Wellesley trail network displayed on map (Brook Path, Cochituate Rail Trail, etc.)
- 📍 Nearest bathroom finder — ranks all stops by distance from your location
- 🏃 GPS run recording with live distance, pace, and time
- 🗓 Route builder — tap to plan a route, snaps to roads and trails via GraphHopper
- 📈 Elevation gain shown while building and on saved routes
- 📤 Export/import pins via group chat

## For your running group
Just share the link: **https://andrewmyerson-atm.github.io/runstop**

On iPhone: open in Safari → tap Share → Add to Home Screen for a full-screen app experience.

## Updating the app
1. Edit `index.html` on GitHub (or replace the file)
2. Changes go live within ~60 seconds automatically
